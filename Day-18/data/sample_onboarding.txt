1. Primary Technical Prerequisites:
Every intern must configure their local development workstation with the following verified toolchain:
- Python runtime: Version 3.10 or higher (Python 3.13 recommended)
- Integrated Development Environment: Visual Studio Code with Python, Pylance, and Jupyter extensions
- Version Control: Git 2.40+ configured with professional GitHub credentials
- Terminal Environment: PowerShell 7+ on Windows or Zsh/Bash on macOS/Linux

2. Access Provisioning and Communication Channels:
During Day 1 of onboarding, interns receive access credentials to:
- Linkific Training Slack workspace (#general, #announcements, #internship-support)
- GitHub organization repository access for daily task submission and code review
- Shared technical documentation and curriculum roadmap resources

3. Security Acknowledgement & Confidentiality Agreement:
Prior to beginning technical assignments, all interns must review, sign, and submit the Linkific Corporate Confidentiality and Data Protection Agreement.
Under this agreement, interns agree never to upload proprietary internal code, customer data, or live production API keys to public repositories or unapproved third-party commercial services.

4. First-Week Milestone Checklist:
By the end of Week 1, interns must successfully:
- Complete local environment health checks
- Clone their assigned Linkific-Tasks repository
- Execute baseline Python, NumPy, and Pandas diagnostic notebooks
- Submit their initial pull request following conventional Git commit standards
