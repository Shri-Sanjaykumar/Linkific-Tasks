1. The 5-Stage Project Lifecycle:
All AI/ML projects and technical deliverables follow an established 5-stage engineering lifecycle:
- Stage 1: Problem Definition & Requirement Analysis (Understanding input constraints, objectives, and success criteria)
- Stage 2: Data Exploration & Preprocessing (Sanitizing raw datasets, handling missing values, exploratory analysis)
- Stage 3: Algorithmic Modeling & Prototype Development (Baseline model construction, feature selection, pipeline architecture)
- Stage 4: Evaluation, Testing & Hyperparameter Tuning (Cross-validation, quantitative benchmarking, error analysis)
- Stage 5: Documentation, Packaging & Demonstration (Technical writeup, architecture diagrams, live demo readiness)

2. Quality Assurance & Pre-Submission Checklist:
Before submitting any project milestone, interns must complete the following QA checklist:
- Verify zero syntax errors and clean linting via Flake8 / Ruff
- Confirm that all automated test cases pass with 100% exit code 0
- Ensure all figures and visual artifacts are natively rendered and embedded
- Verify that no private API keys, tokens, or confidential data are present
- Update README with comprehensive setup and execution instructions

3. Git Branching and Release Management:
All active development occurs on feature branches branched from `main`.
Branches must follow conventional naming: `feature/day-XX-<topic>` or `fix/day-XX-<issue>`.
Direct force-pushes to the primary branch are strictly prohibited.
