# Day 3 – Python Data Structures & File Handling

## Task
Learn core Python data structures and basic file handling to build a console-based data storage application.

## Concepts Practiced
- Lists
- Tuples
- Dictionaries
- Sets
- File handling

## Project
**Student Record Management System**

A console application that allows users to add new student records, assign subject marks, and view all saved records. Student records are represented using dictionaries inside a list, fixed subjects are organized in a tuple, unique roll numbers are tracked with a set, and all data is persistently stored and loaded from a text file (`students.txt`).

## Deliverables
- Student Record Management System (`student_record_management.py`)
- Text file storage (`students.txt`)
- GitHub submission
