# AI/ML Learning Roadmap

This document outlines the step-by-step learning roadmap planned for the **Linkific AI/ML Internship**.

> **Note:** This is a forward-looking **learning roadmap** for my internship training period, not a list of topics I have already completed or mastered.

---

## 📌 Step-by-Step Learning Progression

```text
1. Python Basics & Scripting
        ↓
2. Data Handling & Analysis (NumPy, Pandas)
        ↓
3. Machine Learning Fundamentals (Supervised & Unsupervised Learning)
        ↓
4. Deep Learning Concepts (Neural Networks)
        ↓
5. Generative AI & LLM Basics
        ↓
6. Practical Projects & Implementation
```

---

## 📍 Details of Each Stage

### Stage 1: Python Programming & Environment Setup (Day 1 Focus)
- Setup Python, VS Code, Git, and Jupyter Notebook.
- Understand data structures (lists, dictionaries, functions).

### Stage 2: Data Manipulation & Exploration (Upcoming)
- Handling numerical arrays using **NumPy**.
- Loading, cleaning, and filtering datasets using **Pandas**.
- Visualizing data trends with simple charts.

### Stage 3: Machine Learning Fundamentals (Upcoming)
- Understanding train/test splits.
- Linear Regression, Logistic Regression, Decision Trees.
- Basic model evaluation metrics (Accuracy, Mean Squared Error).

### Stage 4: Deep Learning Foundations (Upcoming)
- Introduction to Artificial Neural Networks (ANNs).
- Understanding weights, biases, activation functions, and loss.

### Stage 5: Generative AI Basics (Upcoming)
- Understanding prompt engineering and how Large Language Models work.

### Stage 6: Practical Projects (Upcoming)
- Applying concepts to real datasets and internship problem statements.
