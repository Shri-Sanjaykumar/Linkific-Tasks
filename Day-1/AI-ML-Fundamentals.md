# AI/ML Fundamentals — Beginner Notes

These notes summarize the core concepts discussed during Day 1 of the internship.

---

## 1. Artificial Intelligence (AI)
Artificial Intelligence is a broad field of computer science focused on building smart systems capable of performing tasks that typically require human intelligence.

- **Examples:** Voice assistants (Siri, Alexa), chess-playing bots, route recommendations on Google Maps.

---

## 2. Machine Learning (ML)
Machine Learning is a subset of AI. Instead of writing fixed rules by hand, we train algorithms on historical data so they can learn patterns and make predictions on new data.

- **How it works:** Data + Answers $\rightarrow$ Model learns Rules $\rightarrow$ Model predicts on new data.
- **Examples:** Email spam filters, product recommendations on Amazon, predicting house prices based on features.

---

## 3. Deep Learning (DL)
Deep Learning is a subset of Machine Learning that uses multi-layered Artificial Neural Networks inspired by how the human brain processes information.

- **Why use it:** Traditional ML needs manual feature extraction. Deep Learning can automatically extract patterns from raw, complex data like images, video, and audio.
- **Examples:** Face unlock on smartphones, self-driving car vision, automated speech-to-text.

---

## 4. Generative AI (GenAI)
Generative AI is a branch of AI/Deep Learning designed to create new, original content rather than just analyzing or classifying existing data.

- **Difference:** Traditional ML predicts a category or number (e.g., "Is this an image of a cat?"). Generative AI generates new content (e.g., "Draw a cat sitting in a garden").
- **Examples:** ChatGPT, GitHub Copilot (code generation), Midjourney (image generation).

---

## 5. Summary Comparison

| Concept | What it Does | Simple Example |
| :--- | :--- | :--- |
| **Artificial Intelligence** | Broad goal to make machines perform smart tasks | GPS navigation system calculating the best route |
| **Machine Learning** | Learns patterns from data to make predictions | Spam filter detecting junk emails based on words |
| **Deep Learning** | Uses deep neural networks to process complex data | Detecting objects in camera feeds for autonomous driving |
| **Generative AI** | Creates new content (text, code, images, audio) | Writing an essay or generating an illustration from a prompt |

---

## 6. Key Takeaways
- AI is the broad umbrella; Machine Learning is inside AI; Deep Learning is inside ML; Generative AI builds on deep learning models.
- Different problems need different tools — tabular data often works best with classic ML, while images and unstructured text benefit from DL and GenAI.
