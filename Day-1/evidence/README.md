## 📌 Guidelines for Evidence Capture
1. Save images in `.png` or `.jpg` format.
2. Ensure terminal commands and corresponding outputs are clearly legible.
3. Reference saved images within markdown documentation using relative paths:
   ```markdown
   ![Python Verification](python-version.png)
   ```
