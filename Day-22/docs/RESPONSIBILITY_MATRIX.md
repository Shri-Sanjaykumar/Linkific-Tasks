## 2. Agent Interaction & Boundary Principles

1. **Role-Governed State Ownership**: Agents cannot mutate fields outside their assigned domain. The `ResearchAgent` owns `research_findings`, `AnalyzerAgent` owns `analysis_result`, `CriticAgent` owns `critic_reviews`, `WriterAgent` owns `final_report`, and `CoordinatorAgent` owns `execution_plan` and `current_status`.
2. **Adversarial Separation of Concerns**: The `CriticAgent` never modifies content directly; it only flags defects and suggests remediation. The `AnalyzerAgent` and `ResearchAgent` must execute the actual fixes.
3. **Traceability by Design**: No claim may appear in the final report without verified provenance in `sample_docs.json` tracked through the `Evidence Traceability Matrix`.
4. **Resilience & Circuit Breaking**: The `CoordinatorAgent` ensures the system cannot loop indefinitely if consensus is not reached, enforcing a deterministic max-revision cap (`max_revisions = 2`).
